# T10 — เสิร์ฟหน้าเว็บที่ build แล้ว
- ใครเป็นคนทำ: backend
- ชื่อฟังก์ชัน: `create_app(db_path, static_dir)` → mount static ที่ `/`
- สิ่งที่ต้องทำ: เพิ่ม parameter `static_dir` ตาม Produces · ถ้ามีค่า mount `StaticFiles(directory=static_dir, html=True)` ที่ `/` หลัง include router `/api` ทั้งหมด (ให้ `/api/*` มาก่อน) · `app` ระดับ module อ่าน env `STATIC_DIR`
- ไฟล์ที่แก้: backend/app/main.py, backend/tests/test_static.py
- Produces: env `STATIC_DIR`: ถ้าตั้งไว้ `GET /` ได้ `index.html` และไฟล์ใต้โฟลเดอร์นั้นเสิร์ฟเป็น static ส่วน `/api/*` ทำงานเหมือนเดิม · ไม่ตั้ง → ไม่เสิร์ฟหน้าเว็บ · ตั้งแต่โฟลเดอร์ไม่มี → app start ไม่ขึ้น · `create_app(db_path: str, static_dir: str | None = None) -> FastAPI` และ `app = create_app(os.environ.get("DATABASE_PATH", "todo.db"), os.environ.get("STATIC_DIR"))`
- Uses from earlier tasks: `create_app(db_path: str) -> FastAPI` ใน `backend/app/main.py` และ `app = create_app(os.environ.get("DATABASE_PATH", "todo.db"))` (T2) · fixture `client` (TestClient บน DB ชั่วคราวใน `tmp_path`) ใน `backend/tests/conftest.py` (T2)
- ผลที่ต้องได้: ตั้ง static_dir เป็นโฟลเดอร์ชั่วคราวที่มี `index.html` → `GET /` 200 ได้เนื้อหาไฟล์ และ `GET /api/todos` ยังได้ JSON · ไม่ตั้ง → `GET /` 404 · โฟลเดอร์ไม่มีจริง → `create_app()` raise · เทสต์เดิมยังผ่าน
- วิธีตรวจงาน: `cd backend && .venv/bin/pytest -v && .venv/bin/ruff check .` → ผ่านทั้งหมด และมีเทสต์อย่างน้อย: `test_serves_index_html`, `test_api_still_json_with_static`, `test_no_static_dir_root_404`, `test_missing_static_dir_raises`
