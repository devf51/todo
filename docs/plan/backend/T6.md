# T6 — API หมวดหมู่ + ผูก todo กับหมวด
- ใครเป็นคนทำ: backend
- ชื่อฟังก์ชัน: router `/api/categories` ใน `backend/app/categories.py` → `GET` / `POST /api/categories`, `PATCH` / `DELETE /api/categories/{id}` · `category_id` ใน `POST` / `PATCH /api/todos`
- สิ่งที่ต้องทำ: ทำ 4 endpoint ของหมวดตาม Produces: name ตัดช่องว่างหน้าหลังก่อน validate 1–50 ตัวอักษร · ชื่อซ้ำ (ตรงตัวหลังตัดช่องว่าง) ทั้งตอนสร้างและเปลี่ยนชื่อ → จับ `sqlite3.IntegrityError` แล้วตอบ 409 · เปลี่ยนชื่อเป็นชื่อเดิมของตัวเอง → 200 · ลบหมวดใช้ `ON DELETE SET NULL` ของ schema (ต้องมี `PRAGMA foreign_keys = ON`) · todo รับ `category_id` ใน POST / PATCH ถ้าไม่มีหมวดนั้น → 422 `{"detail": "category not found"}` · path id และ `category_id` ใน body ใช้ช่วง `ge=1, le=2**63-1` · include router ใน `create_app()`
- ไฟล์ที่แก้: backend/app/categories.py, backend/app/main.py, backend/app/todos.py, backend/tests/test_categories.py, backend/tests/test_todos.py
- Produces: `GET /api/categories` → `200 Category[]` เรียงตาม name · `POST /api/categories` body `{name: string}` (ตัดช่องว่างหน้าหลัง, 1–50 ตัวอักษร) → `201 Category` · `409 {detail: "category name already exists"}` · `422 {detail}` · `PATCH /api/categories/{id}` body `{name: string}` → `200 Category` · `404 {detail: "category not found"}` · `409 {detail: "category name already exists"}` · `422 {detail}` · id ใน path นอกช่วง 1..9223372036854775807 → `422 {detail}` · `DELETE /api/categories/{id}` → `204` (todo ที่อยู่หมวดนี้ได้ `category_id: null`) · `404 {detail: "category not found"}` · id ใน path นอกช่วง 1..9223372036854775807 → `422 {detail}` · `Category = {id: int, name: string}` · `POST /api/todos` และ `PATCH /api/todos/{id}` รับ `category_id?: int|null` เพิ่ม (`null` = ไม่มีหมวด) → `422 {detail: "category not found"}` ถ้าไม่มีหมวดนั้น · `422 {detail}` ถ้านอกช่วง 1..9223372036854775807
- Uses from earlier tasks: `Todo = {id: int, title: string, done: bool, due_date: string|null, priority: "low"|"medium"|"high", category_id: int|null}` (ค่าเริ่มต้น `due_date: null`, `priority: "medium"`, `category_id: null`) (T2) · `create_app(db_path: str) -> FastAPI` ใน `backend/app/main.py` และ `app = create_app(os.environ.get("DATABASE_PATH", "todo.db"))` (T2) · fixture `client` (TestClient บน DB ชั่วคราวใน `tmp_path`) ใน `backend/tests/conftest.py` (T2) · `POST /api/todos` body `{title: string, due_date?: string|null, priority?: "low"|"medium"|"high"}` → `201 Todo` · `422 {detail}` ถ้า due_date ไม่ใช่วันที่จริงในรูปแบบ `YYYY-MM-DD` หรือ priority ไม่ใช่ 3 ค่านี้ (T4) · `PATCH /api/todos/{id}` body `{title?: string, done?: bool, due_date?: string|null, priority?: "low"|"medium"|"high"}` → `200 Todo` (ไม่ส่ง field = ไม่เปลี่ยน, `due_date: null` = ลบวันกำหนดส่ง, `title` / `done` / `priority` เป็น `null` → 422) · `404 {detail: "todo not found"}` · `422 {detail}` (T4)
- ผลที่ต้องได้: สร้างหมวด → 201 และเห็นใน `GET /api/categories` · ชื่อซ้ำ → 409 · ชื่อว่าง / ช่องว่าง / 51 ตัวอักษร → 422 · เปลี่ยนชื่อ → 200, todo ในหมวดยังมี `category_id` เดิม · เปลี่ยนชื่อชนหมวดอื่น → 409 · ลบหมวด → 204 todo ในหมวดยังอยู่และได้ `category_id: null` · id หมวดที่ไม่มี (PATCH / DELETE) → 404 · todo POST / PATCH ด้วย `category_id` ที่มี → บันทึก, ที่ไม่มี → 422, `null` → ไม่มีหมวด
- วิธีตรวจงาน: `cd backend && .venv/bin/pytest -v && .venv/bin/ruff check .` → ผ่านทั้งหมด และมีเทสต์อย่างน้อย: `test_create_category`, `test_duplicate_category_409`, `test_invalid_category_name_422` (parametrize 3 ค่า), `test_list_categories_sorted`, `test_rename_category_keeps_todo_link`, `test_rename_to_existing_name_409`, `test_rename_to_own_name_200`, `test_delete_category_sets_todos_null`, `test_unknown_category_404` (PATCH + DELETE), `test_todo_with_category`, `test_todo_unknown_category_422`, `test_todo_category_null`, `test_huge_ids_422` (path id หมวด + `category_id` ใน body)
