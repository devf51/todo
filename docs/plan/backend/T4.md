# T4 — วันกำหนดส่ง + ลำดับความสำคัญ + การเรียง
- ใครเป็นคนทำ: backend
- ชื่อฟังก์ชัน: ขยาย `POST /api/todos`, `PATCH /api/todos/{id}`, `GET /api/todos`
- สิ่งที่ต้องทำ: รับ `due_date` (วันที่จริงรูปแบบ `YYYY-MM-DD` เท่านั้น: ปฏิเสธ `"31/12/2026"`, `"2026-02-30"`, ตัวเลข, datetime เช่น `"2026-12-31T00:00:00"`) และ `priority` (`low` / `medium` / `high`) ใน POST และ PATCH · PATCH แยก "ไม่ส่ง field" (ไม่เปลี่ยน) กับ `null` (ลบวันกำหนดส่ง) · `priority: null` → 422 · เปลี่ยนการเรียงของ `GET` เป็น `ORDER BY due_date IS NULL, due_date, id`
- ไฟล์ที่แก้: backend/app/todos.py, backend/tests/test_todos.py
- Produces: `POST /api/todos` body `{title: string, due_date?: string|null, priority?: "low"|"medium"|"high"}` → `201 Todo` · `422 {detail}` ถ้า due_date ไม่ใช่วันที่จริงในรูปแบบ `YYYY-MM-DD` หรือ priority ไม่ใช่ 3 ค่านี้ · `PATCH /api/todos/{id}` body `{title?: string, done?: bool, due_date?: string|null, priority?: "low"|"medium"|"high"}` → `200 Todo` (ไม่ส่ง field = ไม่เปลี่ยน, `due_date: null` = ลบวันกำหนดส่ง) · `404 {detail: "todo not found"}` · `422 {detail}` · `GET /api/todos` → `200 Todo[]` เรียง `due_date` น้อยไปมาก, `due_date: null` อยู่ท้าย, เท่ากันเรียงตาม id
- Uses from earlier tasks: `Todo = {id: int, title: string, done: bool, due_date: string|null, priority: "low"|"medium"|"high", category_id: int|null}` (ค่าเริ่มต้น `due_date: null`, `priority: "medium"`, `category_id: null`) (T2) · fixture `client` (TestClient บน DB ชั่วคราวใน `tmp_path`) ใน `backend/tests/conftest.py` (T2)
- ผลที่ต้องได้: POST พร้อม `due_date: "2026-12-31"`, `priority: "high"` → 201 ได้ค่ากลับ · ไม่ส่ง → `null` / `"medium"` · วันที่ผิดทุกแบบข้างบน → 422 · `priority: "urgent"` → 422 · PATCH แก้ `due_date`, `priority` ได้ · `due_date: null` → ลบ · PATCH ที่ไม่ส่ง due_date ไม่ลบค่าเดิม · `GET` เรียงตามวันที่ใกล้สุดก่อน null อยู่ท้าย
- วิธีตรวจงาน: `cd backend && .venv/bin/pytest -v && .venv/bin/ruff check .` → ผ่านทั้งหมด (รวมเทสต์ของ T2) และมีเทสต์อย่างน้อย: `test_create_with_due_date_and_priority`, `test_defaults_when_omitted`, `test_invalid_due_date_422` (parametrize 4 ค่า), `test_invalid_priority_422`, `test_patch_due_date_and_priority`, `test_patch_due_date_null_clears`, `test_patch_without_due_date_keeps_value`, `test_list_sorted_by_due_date_nulls_last`
