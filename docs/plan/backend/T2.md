# T2 — API todo พื้นฐาน + DB schema
- ใครเป็นคนทำ: backend
- ชื่อฟังก์ชัน: `create_app()`, `init_db()`, router `/api/todos` → `GET` / `POST /api/todos`, `PATCH` / `DELETE /api/todos/{id}`
- สิ่งที่ต้องทำ: สร้าง schema ทั้ง 2 ตาราง (`categories`, `todos`) ตามหัวข้อ "ข้อมูล" ใน architecture ทุกคอลัมน์ ด้วย `CREATE TABLE IF NOT EXISTS` ตอน `create_app()` · ทุก connection เปิด `PRAGMA foreign_keys = ON` · connection ใหม่ต่อ request · ทำ 4 endpoint ตาม Produces: title ตัดช่องว่างหน้าหลังก่อน validate 1–200 ตัวอักษร · PATCH แก้เฉพาะ field ที่ส่งมา (`title` ถูก validate แบบเดียวกับ POST) · SQL ใช้ placeholder `?` เท่านั้น · ยังไม่รับ `due_date` / `priority` / `category_id` จาก body (field เกินถูกเมิน) แต่ส่งกลับใน `Todo` ด้วยค่าเริ่มต้น
- ไฟล์ที่แก้: backend/app/__init__.py, backend/app/main.py, backend/app/db.py, backend/app/todos.py, backend/tests/conftest.py, backend/tests/test_todos.py
- Produces: `GET /api/todos` → `200 Todo[]` เรียงตาม id น้อยไปมาก · `POST /api/todos` body `{title: string}` (ตัดช่องว่างหน้าหลัง, 1–200 ตัวอักษร) → `201 Todo` · `422 {detail}` ถ้า title ว่าง / มีแต่ช่องว่าง / ยาวเกิน 200 · `PATCH /api/todos/{id}` body `{title?: string, done?: bool}` → `200 Todo` · `404 {detail: "todo not found"}` · `422 {detail}` · `DELETE /api/todos/{id}` → `204` · `404 {detail: "todo not found"}` · `Todo = {id: int, title: string, done: bool, due_date: string|null, priority: "low"|"medium"|"high", category_id: int|null}` (ค่าเริ่มต้น `due_date: null`, `priority: "medium"`, `category_id: null`) · `create_app(db_path: str) -> FastAPI` ใน `backend/app/main.py` และ `app = create_app(os.environ.get("DATABASE_PATH", "todo.db"))` · fixture `client` (TestClient บน DB ชั่วคราวใน `tmp_path`) ใน `backend/tests/conftest.py`
- Uses from earlier tasks: none
- ผลที่ต้องได้: `POST /api/todos` `{"title":"ซื้อนม"}` → 201 `done: false`, `due_date: null`, `priority: "medium"`, `category_id: null` และเห็นใน `GET` · title ว่าง / `"   "` / 201 ตัวอักษร → 422 และ `GET` ยังมีจำนวนเท่าเดิม · title มีช่องว่างหน้าหลังถูกตัด · `PATCH` `done: true` / `done: false` / `title` ใหม่ → 200 ค่าตามนั้น และ `GET` เห็นค่าใหม่ · `PATCH` title ว่าง → 422 · `DELETE` → 204 แล้ว `GET` ไม่มี · `PATCH` / `DELETE` id ที่ไม่มี → 404 `{"detail": "todo not found"}` · ข้อมูลอยู่รอดเมื่อสร้าง `create_app()` ใหม่บนไฟล์ DB เดิม
- วิธีตรวจงาน: `cd backend && .venv/bin/pytest tests/test_todos.py -v && .venv/bin/ruff check .` → ผ่านทั้งหมด และมีเทสต์อย่างน้อย: `test_create_todo_returns_201_with_defaults`, `test_create_todo_trims_title`, `test_create_todo_rejects_empty_blank_and_too_long_title`, `test_list_todos`, `test_patch_done_true_and_false`, `test_patch_title`, `test_patch_rejects_blank_title`, `test_delete_todo`, `test_patch_and_delete_unknown_id_404`, `test_data_persists_across_app_instances`
