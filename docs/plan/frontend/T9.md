# T9 — หน้าเว็บ: ตัวกรองรายการ
- ใครเป็นคนทำ: frontend
- ชื่อฟังก์ชัน: `listTodos(filters?)` → `<Filters />` ใน `<App />`
- สิ่งที่ต้องทำ: ขยาย `listTodos` ให้รับตัวกรองตาม Produces (สร้าง query ด้วย `URLSearchParams` ส่งเฉพาะค่าที่มี, ไม่ส่ง `status=all`) · `<Filters />` ตาม Produces · `<App />` เก็บตัวกรองใน state แล้วโหลดรายการใหม่ทุกครั้งที่ตัวกรองเปลี่ยน และหลังเพิ่ม / แก้ / ลบ ใช้ตัวกรองปัจจุบัน
- ไฟล์ที่แก้: frontend/src/api.ts, frontend/src/api.test.ts, frontend/src/Filters.tsx, frontend/src/Filters.test.tsx, frontend/src/App.tsx, frontend/src/App.test.tsx
- Produces: type `TodoFilters = {status?: "all" | "active" | "done"; category_id?: number; priority?: "low" | "medium" | "high"}` ใน `frontend/src/api.ts` · `listTodos(filters?: TodoFilters): Promise<Todo[]>` (ส่งเฉพาะ query ที่มีค่า, ไม่ส่ง `status=all`) · `<Filters value={TodoFilters} categories={Category[]} onChange={(f: TodoFilters) => void} />` ใน `frontend/src/Filters.tsx`: select "สถานะ" (ทั้งหมด / ยังไม่เสร็จ / เสร็จแล้ว), "กรองหมวด" (ทั้งหมด + หมวดทั้งหมด), "กรองความสำคัญ" (ทั้งหมด / low / medium / high) · เปลี่ยนแล้ว `<App />` โหลดรายการใหม่ทันที
- Uses from earlier tasks: `GET /api/todos?status=all|active|done&category_id=<int>&priority=low|medium|high` (ทุกตัวไม่บังคับ, ไม่ส่ง status = all, หลายตัวรวมกันแบบ AND, category_id ที่ไม่มีได้ `[]`, category_id นอกช่วง 1..9223372036854775807 → 422) → `200 Todo[]` เรียงแบบเดิม · `422 {detail}` ถ้าค่าไม่ถูกต้อง (T8) · type `Todo = {id: number; title: string; done: boolean; due_date: string | null; priority: "low" | "medium" | "high"; category_id: number | null}` ใน `frontend/src/api.ts` (T3) · type `Category = {id: number; name: string}` ใน `frontend/src/api.ts` (T7) · `listCategories(): Promise<Category[]>` (T7) · `<Categories categories={Category[]} onChange={() => void} />` ใน `frontend/src/Categories.tsx`: ช่อง "ชื่อหมวด" + ปุ่ม "เพิ่มหมวด", แต่ละหมวดมีปุ่ม "เปลี่ยนชื่อ" และ "ลบหมวด" · ฟอร์ม todo มี select "หมวด" (ตัวเลือก "ไม่มีหมวด" + หมวดทั้งหมด) · แต่ละรายการแสดงชื่อหมวด (T7)
- ผลที่ต้องได้: เลือก "ยังไม่เสร็จ" → `GET /api/todos?status=active` และรายการเปลี่ยน · เลือกหมวด → `category_id=<id>` · เลือกความสำคัญ → `priority=...` · เลือกหลายตัว → query ครบทุกตัว · กลับเป็น "ทั้งหมด" → ไม่ส่ง query นั้น · เทสต์เดิมยังผ่าน
- วิธีตรวจงาน: `cd frontend && npm test && npm run build` → ผ่านทั้งหมด build exit 0 · มีเทสต์อย่างน้อย: `api.test.ts` สร้าง query ถูก (ไม่มีตัวกรอง, ครบ 3 ตัว, ไม่ส่ง `status=all`), `Filters.test.tsx` เรียก `onChange` ถูกค่า, `App.test.tsx` เปลี่ยนตัวกรองแล้ว fetch URL ใหม่และแสดงผลตามที่ได้
