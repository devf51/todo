# T5 — หน้าเว็บ: วันกำหนดส่ง + ความสำคัญ
- ใครเป็นคนทำ: frontend
- ชื่อฟังก์ชัน: `createTodo()`, `updateTodo()` รับ field เพิ่ม → ฟอร์มใน `<App />`
- สิ่งที่ต้องทำ: ขยาย type ของ `createTodo` / `updateTodo` ตาม Produces · เพิ่มช่อง "วันกำหนดส่ง" และ "ความสำคัญ" ในฟอร์มเพิ่มและฟอร์มแก้ไข (ช่องวันที่ว่าง = ส่ง `null`) · แสดงวันกำหนดส่ง (หรือไม่แสดงถ้าไม่มี) และความสำคัญบนแต่ละรายการ · ใช้ลำดับที่ API ส่งมา ไม่เรียงเองฝั่ง client
- ไฟล์ที่แก้: frontend/src/api.ts, frontend/src/api.test.ts, frontend/src/App.tsx, frontend/src/App.test.tsx, frontend/src/App.css
- Produces: `createTodo(input: {title: string; due_date?: string | null; priority?: "low" | "medium" | "high"}): Promise<Todo>` · `updateTodo(id: number, patch: {title?: string; done?: boolean; due_date?: string | null; priority?: "low" | "medium" | "high"}): Promise<Todo>` · ฟอร์มเพิ่มและฟอร์มแก้ไขมีช่อง "วันกำหนดส่ง" (`<input type="date">`, เว้นว่างได้) และ select "ความสำคัญ" (low / medium / high ค่าเริ่มต้น medium) · แต่ละรายการแสดงวันกำหนดส่งและความสำคัญ
- Uses from earlier tasks: type `Todo = {id: number; title: string; done: boolean; due_date: string | null; priority: "low" | "medium" | "high"; category_id: number | null}` ใน `frontend/src/api.ts` (T3) · ทุกฟังก์ชันใน `api.ts` throw `ApiError {status: number, detail: string}` เมื่อ status ไม่ใช่ 2xx (`detail` จาก body ถ้าเป็น string, ไม่งั้นข้อความทั่วไป) (T3) · `listTodos(): Promise<Todo[]>` (T3) · `deleteTodo(id: number): Promise<void>` (T3) · `<App />` หน้า `/`: ช่อง "ชื่องาน" + ปุ่ม "เพิ่ม", แต่ละรายการเป็น `<li>` มี checkbox (accessible name = title), ปุ่ม "แก้ไข" → ช่องแก้ชื่อ + ปุ่ม "บันทึก", ปุ่ม "ลบ" · error แสดงใน `role="alert"` (T3) · `POST /api/todos` body `{title: string, due_date?: string|null, priority?: "low"|"medium"|"high"}` → `201 Todo` · `422 {detail}` ถ้า due_date ไม่ใช่วันที่จริงในรูปแบบ `YYYY-MM-DD` หรือ priority ไม่ใช่ 3 ค่านี้ (T4) · `PATCH /api/todos/{id}` body `{title?: string, done?: bool, due_date?: string|null, priority?: "low"|"medium"|"high"}` → `200 Todo` (ไม่ส่ง field = ไม่เปลี่ยน, `due_date: null` = ลบวันกำหนดส่ง, `title` / `done` / `priority` เป็น `null` → 422) · `404 {detail: "todo not found"}` · `422 {detail}` (T4) · `GET /api/todos` → `200 Todo[]` เรียง `due_date` น้อยไปมาก, `due_date: null` อยู่ท้าย, เท่ากันเรียงตาม id (T4)
- ผลที่ต้องได้: เพิ่ม todo พร้อมวันที่และความสำคัญ → body มี `due_date` / `priority` และรายการแสดงทั้งสองค่า · ไม่เลือกความสำคัญ → ส่ง `"medium"` · แก้วันที่ / ความสำคัญ → `PATCH` ถูก · ล้างช่องวันที่ตอนแก้ → `PATCH due_date: null` · เทสต์ของ T3 ยังผ่าน
- วิธีตรวจงาน: `cd frontend && npm test && npm run build` → ผ่านทั้งหมด build exit 0 · มีเทสต์อย่างน้อย: เพิ่มพร้อมวันที่ + ความสำคัญ, ค่าเริ่มต้น medium, แก้แล้วล้างวันที่ส่ง `null`, แสดงค่าบนรายการ
