# T3 — หน้าเว็บ todo พื้นฐาน
- ใครเป็นคนทำ: frontend
- ชื่อฟังก์ชัน: `listTodos()`, `createTodo()`, `updateTodo()`, `deleteTodo()` ใน `api.ts` → `<App />`
- สิ่งที่ต้องทำ: เขียน `api.ts` (fetch ไป path แบบ relative `/api/...`, ใส่ `Content-Type: application/json`) และ `<App />` ภาษาไทยตาม Produces: โหลดรายการตอนเปิดหน้า · เพิ่ม (ปุ่ม "เพิ่ม" ใช้ไม่ได้เมื่อช่องว่าง, สำเร็จแล้วล้างช่อง) · ติ๊ก / ยกเลิกติ๊ก (รายการเสร็จแสดงขีดฆ่า) · แก้ชื่อ · ลบ · ทุกการกระทำเปลี่ยนจอหลัง server ตอบสำเร็จเท่านั้น · error แสดงใน `role="alert"` และไม่ล้างค่าที่พิมพ์ · ห้ามใช้ `dangerouslySetInnerHTML`
- ไฟล์ที่แก้: frontend/src/api.ts, frontend/src/api.test.ts, frontend/src/App.tsx, frontend/src/App.test.tsx, frontend/src/App.css
- Produces: type `Todo = {id: number; title: string; done: boolean; due_date: string | null; priority: "low" | "medium" | "high"; category_id: number | null}` ใน `frontend/src/api.ts` · ทุกฟังก์ชันใน `api.ts` throw `ApiError {status: number, detail: string}` เมื่อ status ไม่ใช่ 2xx (`detail` จาก body ถ้าเป็น string, ไม่งั้นข้อความทั่วไป) · `listTodos(): Promise<Todo[]>` · `createTodo(input: {title: string}): Promise<Todo>` · `updateTodo(id: number, patch: {title?: string; done?: boolean}): Promise<Todo>` · `deleteTodo(id: number): Promise<void>` · `<App />` หน้า `/`: ช่อง "ชื่องาน" + ปุ่ม "เพิ่ม", แต่ละรายการเป็น `<li>` มี checkbox (accessible name = title), ปุ่ม "แก้ไข" → ช่องแก้ชื่อ + ปุ่ม "บันทึก", ปุ่ม "ลบ" · error แสดงใน `role="alert"`
- Uses from earlier tasks: `GET /api/todos` → `200 Todo[]` เรียงตาม id น้อยไปมาก (T2) · `POST /api/todos` body `{title: string}` (ตัดช่องว่างหน้าหลัง, 1–200 ตัวอักษร) → `201 Todo` · `422 {detail}` ถ้า title ว่าง / มีแต่ช่องว่าง / ยาวเกิน 200 (T2) · `PATCH /api/todos/{id}` body `{title?: string, done?: bool}` → `200 Todo` (body `{}` → 200 ค่าเดิม, `title: null` / `done: null` → 422) · `404 {detail: "todo not found"}` · `422 {detail}` · id ใน path นอกช่วง 1..9223372036854775807 → `422 {detail}` (T2) · `DELETE /api/todos/{id}` → `204` · `404 {detail: "todo not found"}` · id ใน path นอกช่วง 1..9223372036854775807 → `422 {detail}` (T2) · `Todo = {id: int, title: string, done: bool, due_date: string|null, priority: "low"|"medium"|"high", category_id: int|null}` (ค่าเริ่มต้น `due_date: null`, `priority: "medium"`, `category_id: null`) (T2)
- ผลที่ต้องได้: เปิด `/` เห็นรายการจาก API · พิมพ์ชื่อแล้วกด "เพิ่ม" → รายการใหม่ขึ้น · ติ๊ก → `PATCH done: true` และแสดงว่าเสร็จ · แก้ชื่อแล้ว "บันทึก" → ชื่อใหม่ · "ลบ" → รายการหาย · API ตอบ 422 / 500 → ข้อความใน `role="alert"` และช่องที่พิมพ์ยังอยู่ · `api.ts` ส่ง method / URL / body ถูก และ throw `ApiError` เมื่อไม่ใช่ 2xx
- วิธีตรวจงาน: `cd frontend && npm test -- src/api.test.ts src/App.test.tsx && npm run build` → ผ่านทั้งหมด build exit 0 · ลองจริง: รัน backend + `npm run dev` แล้วเปิด `http://localhost:5173` เพิ่ม / ติ๊ก / แก้ / ลบ แล้ว reload → ผลยังอยู่
