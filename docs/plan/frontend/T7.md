# T7 — หน้าเว็บ: จัดการหมวด + เลือกหมวดให้ todo
- ใครเป็นคนทำ: frontend
- ชื่อฟังก์ชัน: `listCategories()`, `createCategory()`, `renameCategory()`, `deleteCategory()` ใน `api.ts` → `<Categories />` · select "หมวด" ใน `<App />`
- สิ่งที่ต้องทำ: เพิ่มฟังก์ชันหมวดใน `api.ts` และ `category_id` ใน `createTodo` / `updateTodo` · `<Categories />` สร้าง / เปลี่ยนชื่อ (แก้ในบรรทัดเดียวกัน แล้วกด "บันทึก") / ลบหมวด แล้วเรียก `onChange` · `<App />` โหลดหมวดตอนเปิดหน้า · หลัง `onChange` โหลดทั้งหมวดและ todo ใหม่ (ให้ todo ของหมวดที่ถูกลบแสดง "ไม่มีหมวด" และชื่อใหม่แสดงทันที) · ฟอร์มเพิ่ม / แก้ไข todo มี select "หมวด" · error 409 / 422 แสดงใน `role="alert"`
- ไฟล์ที่แก้: frontend/src/api.ts, frontend/src/api.test.ts, frontend/src/Categories.tsx, frontend/src/Categories.test.tsx, frontend/src/App.tsx, frontend/src/App.test.tsx, frontend/src/App.css
- Produces: type `Category = {id: number; name: string}` ใน `frontend/src/api.ts` · `listCategories(): Promise<Category[]>` · `createCategory(name: string): Promise<Category>` · `renameCategory(id: number, name: string): Promise<Category>` · `deleteCategory(id: number): Promise<void>` · `createTodo(input: {title: string; due_date?: string | null; priority?: "low" | "medium" | "high"; category_id?: number | null}): Promise<Todo>` · `updateTodo(id: number, patch: {title?: string; done?: boolean; due_date?: string | null; priority?: "low" | "medium" | "high"; category_id?: number | null}): Promise<Todo>` · `<Categories categories={Category[]} onChange={() => void} />` ใน `frontend/src/Categories.tsx`: ช่อง "ชื่อหมวด" + ปุ่ม "เพิ่มหมวด", แต่ละหมวดมีปุ่ม "เปลี่ยนชื่อ" และ "ลบหมวด" · ฟอร์ม todo มี select "หมวด" (ตัวเลือก "ไม่มีหมวด" + หมวดทั้งหมด) · แต่ละรายการแสดงชื่อหมวด
- Uses from earlier tasks: type `Todo = {id: number; title: string; done: boolean; due_date: string | null; priority: "low" | "medium" | "high"; category_id: number | null}` ใน `frontend/src/api.ts` (T3) · ทุกฟังก์ชันใน `api.ts` throw `ApiError {status: number, detail: string}` เมื่อ status ไม่ใช่ 2xx (`detail` จาก body ถ้าเป็น string, ไม่งั้นข้อความทั่วไป) (T3) · `listTodos(): Promise<Todo[]>` (T3) · `deleteTodo(id: number): Promise<void>` (T3) · `<App />` หน้า `/`: ช่อง "ชื่องาน" + ปุ่ม "เพิ่ม", แต่ละรายการเป็น `<li>` มี checkbox (accessible name = title), ปุ่ม "แก้ไข" → ช่องแก้ชื่อ + ปุ่ม "บันทึก", ปุ่ม "ลบ" · error แสดงใน `role="alert"` (T3) · ฟอร์มเพิ่มและฟอร์มแก้ไขมีช่อง "วันกำหนดส่ง" (`<input type="date">`, เว้นว่างได้) และ select "ความสำคัญ" (low / medium / high ค่าเริ่มต้น medium) · แต่ละรายการแสดงวันกำหนดส่งและความสำคัญ (T5) · `GET /api/categories` → `200 Category[]` เรียงตาม name (T6) · `POST /api/categories` body `{name: string}` (ตัดช่องว่างหน้าหลัง, 1–50 ตัวอักษร) → `201 Category` · `409 {detail: "category name already exists"}` · `422 {detail}` (T6) · `PATCH /api/categories/{id}` body `{name: string}` → `200 Category` · `404 {detail: "category not found"}` · `409 {detail: "category name already exists"}` · `422 {detail}` (T6) · `DELETE /api/categories/{id}` → `204` (todo ที่อยู่หมวดนี้ได้ `category_id: null`) · `404 {detail: "category not found"}` (T6) · `Category = {id: int, name: string}` (T6) · `POST /api/todos` และ `PATCH /api/todos/{id}` รับ `category_id?: int|null` เพิ่ม (`null` = ไม่มีหมวด) → `422 {detail: "category not found"}` ถ้าไม่มีหมวดนั้น (T6)
- ผลที่ต้องได้: สร้างหมวด → `POST /api/categories` และหมวดขึ้นในรายการและใน select · ชื่อซ้ำ → ข้อความ error · เปลี่ยนชื่อ → `PATCH` และชื่อบน todo เปลี่ยน · ลบหมวด → `DELETE` และ todo ที่เคยอยู่แสดง "ไม่มีหมวด" · เพิ่ม / แก้ todo เลือกหมวด → body มี `category_id` · เลือก "ไม่มีหมวด" → `category_id: null` · เทสต์เดิมยังผ่าน
- วิธีตรวจงาน: `cd frontend && npm test && npm run build` → ผ่านทั้งหมด build exit 0 · มีเทสต์อย่างน้อย: `api.test.ts` ของ 4 ฟังก์ชันหมวด, `Categories.test.tsx` สร้าง / เปลี่ยนชื่อ / ลบ / แสดง error 409, `App.test.tsx` เลือกหมวดตอนเพิ่ม, ลบหมวดแล้วรายการแสดง "ไม่มีหมวด"
