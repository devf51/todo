## รอบ 1
### ทำไปแล้ว
- POST/PATCH รับ `due_date` (`YYYY-MM-DD` วันที่จริง เท่านั้น) และ `priority`; `GET` เรียง `due_date IS NULL, due_date, id`
### ตัดสินใจ
- `due_date` ใช้ `StrictStr` + regex `\d{4}-\d{2}-\d{2}` + `date.fromisoformat` → ปฏิเสธรูปแบบอื่น, วันที่ไม่มีจริง, ตัวเลข, datetime
- PATCH แยก "ไม่ส่ง" กับ `null` ด้วย `exclude_unset`; `title`/`done`/`priority` เป็น `null` → 422 (เช็กรวมในที่เดียว)
